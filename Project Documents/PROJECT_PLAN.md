# Charrty

## Description

- A jQuery plugin that turns HTML tables, Google Sheets and JavaScript arrays into Google Charts, keeping the underlying data accessible.

## Problem Statement

- Google Charts needs its data in JavaScript, which hides it from screen readers and search engines and means hand-coding each chart.

## Solution Statement

- Use an HTML table (or a Sheet or array) as the data source; the plugin builds the chart and keeps or generates an accessible table alongside it.
